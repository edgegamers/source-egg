# Garry's Mod Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for this small change.

**Goal:** Make GMod selectable and runnable through the existing egg and node.

**Architecture:** Extend the registry, resolve the branch-specific launcher,
and skip managed frameworks for GMod. Reuse current install/update delivery.

**Tech Stack:** Go, SteamCMD, Pelican/Pterodactyl JSON.

**Spec:** `docs/superpowers/specs/2026-11-19-gmod-design.md`

## Global Constraints

- Keep existing game identities and launch behavior intact.
- GMod uses apps 4020/4000 and default map gm_construct.
- No new dependencies or managed Workshop cache.

## Review Focus

- Both public and x86-64 launches must select the matching native binary.
- GMod must boot with the panel's framework toggles left enabled.
- Node preparation must skip GMod framework downloads.
- Managed updates must retain server-added Lua, gamemode and data files outside
  Steam's inventory; shipped files retain normal update behavior.
- Predownload all must include GMod.
